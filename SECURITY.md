# Security

## Issues with this website

If you have found a security problem with shhnote.com itself (its pages, its
headers or its configuration), email **security@shhnote.com** and tell us
privately before telling anyone else. Include what you found and how to
reproduce it. Please don't access other people's data, disrupt the service or
run scans that put heavy load on it while testing. Never send us secret links or
their contents; we don't need them.

## Vulnerabilities in the shhnote software

The encryption, the API and the `@shhnote/client` package this site uses come
from the main repository. Report vulnerabilities in them through its security
policy: https://github.com/shhnote/shhnote/security.

If you aren't sure which one applies, write to security@shhnote.com and we will
pass it on.
