## Things people send

- the password to a tax document, for an accountant;
- a streaming or shared-account login, for family;
- an alarm or key-safe code, for a contractor or a house-sitter;
- a scan of an ID or a contract, for someone who needs it once.

## How it works

Write the secret or attach the file, choose how long it lasts, and copy the link. When the recipient opens it, their browser unlocks it and, for a one-time secret, this site deletes it. No account, no app, nothing to install on either side. [How it works](/en/how-it-works/) explains it in plain language.

## Two small habits

- Change the code or password afterwards when you can, so a link opened by the wrong person doesn't matter for long.
- If you add a passphrase, tell it to the recipient in person or by phone rather than in the same message as the link.
