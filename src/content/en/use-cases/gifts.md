## Ideas

- **Gift cards.** Send the code as a one-time secret, so it isn't left in a chat where someone else could find it later.
- **Surprises.** A message, a photo or a plan that disappears after it's been seen.
- **Treasure hunts.** Each clue as its own link that expires, with a passphrase found at the previous stop.

## How to set it up

Create the secret, choose a one-time view, and set the expiry to cover the time until it should be opened. If the timing matters, a passphrase lets you hand out links early and the key at the right moment.
